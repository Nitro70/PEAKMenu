PEAKMenu, a mod menu for PEAK, by Nitro70
https://github.com/Nitro70/PEAKMenu

Press Insert in game to open it (change the key in the menu's Settings tab).

CLIENT cards work in any lobby, HOST cards need you to be the host.
Settings, favourites and key binds are saved in BepInEx\config\com.nitro70.peakmenu.cfg.
Switches always start off.

To remove the menu, delete this PEAKMenu folder. To remove BepInEx too, delete the BepInEx folder,
winhttp.dll, doorstop_config.ini and .doorstop_version from the PEAK folder.
